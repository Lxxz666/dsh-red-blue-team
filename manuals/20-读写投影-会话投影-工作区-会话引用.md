# 20 · 读写投影类（sessionProjections / workspaceRegistry / sessionReferenceResolver）开发手册

> 对应 TS 版 session-projection（+ session-stats/tool-todo 单元）、dsh-workspace
> 与 session-reference 三个 host 侧能力 seam。全部为**可选能力**：不注册工具、
> 不注入提示词、不写入会话事件（投影单元本身由框架在内存中折叠，产出只在
> 读取时生成）。签名经 `inspect` 核验。

## 2. SessionProjectionRegistry 分节

### 2.1 定位

- 框架驱动、领域计算：注册表只订阅一次 `session/event`（同步监听器），把每个
  已提交事件折叠进每个单元；领域不持有任何订阅。
- `ProjectionDefinition`（dataclass）：`key` / `init` / `apply(state, event)`
  / `view(state)`（缺省恒等）/ `state_version`（≥1）。
- **身份比较契约**：`apply` 返回**同一状态引用**表示不变；引用变化 →
  更新水位 cell + 通知变更流（key, session, 视图值, 致因 seq）。

### 2.2 方法详解

- `register(definition) -> 注销函数`（effect 绑定）
  - key 非空字符串 / `state_version` 正整数 / `apply` 可调用，否则 `ValueError`；
  - 同 key 相同定义 = **引用计数**（同一工具包挂 N 个 preset 注册 N 次，
    最后一个卸载才消失）；同 key 不同定义 `ValueError`；
  - 卸载清空该 key 的全部缓存 cell。
- `on_changed(listener) -> 注销函数`：变更流订阅，签名
  `listener(key, session, view_value, causing_seq)`；异常隔离。
- `_on_event(session, event)`（驱动）：
  - cell（(session_id, key) → (state, watermark_seq)）惰性构建——注册晚于
    事件流时首次触达从 `init` 折叠**整个**内存日志；
  - 否则 `new_state = apply(state, event)`，身份变化才替换 cell 并通知。
- `snapshot(session) -> {"as_of_seq", "values"}`（一致同步切面）
  - `as_of_seq` = 所有值共同反映到的最后事件 seq（空日志 -1）；
  - 惰性构建：cell 缺失 → 从 `init` 折叠全日志；cell 存在但水位落后 →
    **从 cell 状态折叠未覆盖后缀**（绝不丢弃累积状态——本批修复的 bug：
    早期实现从 init 重折后缀会把已折叠状态清零）；
  - 读毕把 cell 提升到最新水位（幂等：重复快照零折叠）。
- `_on_disposed(session)`：清除该会话全部 cell。
- `unit_keys()` / `close()`。

### 2.3 内建单元

| 单元 | state_version | init | apply | view |
|---|---|---|---|---|
| `todos` | 2 | `None` | `todo/write` → 取整表（最新写入胜出）；`turn/start` → `None`（当前有效计划；turn/end 保留刚完成的清单）；其余同引用 | 恒等 |
| `session_stats` | 1 | `{messages, user_messages, assistant_messages, tool_results: 0, started_at, last_activity_at: None}` | 三类 surface 事件构造新 dict（计数 + 墙钟）；其余同引用 | 恒等 |

`ProjectionUnitsPlugin.inject = ("sessionProjections",)`：注册两者，cleanup
逐个注销。

## 3. WorkspaceRegistry 分节

### 3.1 定位

- 工作区 = 规范路径上的稳定 id（`ws-<n>`）+ 显示标题 + 会话归属账本
  （最新在前）。经 storage domain "workspace" 持久化（键 `order` / `records` /
  `archived`；未挂载 storage 则仅内存）。
- 宿主侧：不注册工具、不注入提示词、不写会话事件。删除只移除注册记录，
  目录/用户文件/活跃会话/持久化日志绝不受影响（会话归入 Ungrouped）。

### 3.2 方法详解

- `create(path, title=None) -> Workspace`：`os.path.realpath` 规范化；非目录
  `ValueError`；每规范路径至多一条（重复调用返回现有记录**不改标题**）；
  新记录前置持久顺序。
- `get(id)` / `list()`（同步、持久顺序）/ `resolve_by_path(path)`
  （同一 realpath 规范化；缺失 `ValueError`，不创建）。
- `insert_before(id, before=None) -> 已提交顺序`：DOM 式移动；来源/锚点未知
  `ValueError` 不写；自身为锚 / 已在锚前 / 锚省略且已居末 = 不写完成。
- `delete(id) -> bool`：未知 False。
- `account_session(workspace_id, session_id)`：去重 + 最新在前；
  `sessions_of(workspace_id, include_archived=False)`。
- `archive_session(id)`（已归档不写完成；未知——已记账 ∪ 活跃会话——拒绝）/
  `unarchive_session(id)` / `archived_session_ids`：归档从分组消失但保留席位。
- `group_sessions() -> [{workspace_id, title, path, session_ids}]`：宿主分组视图。
- `SessionWorkspacePlugin`：`session/created` → header.cwd → create + account
  （无 cwd / 非目录静默跳过）。

## 4. SessionReferenceResolver 分节

### 4.1 定位

- 把其他会话准备为**有界、只读**快照（带来源、面向模型的上下文）。
  消费 `ctx.sessionQuery` 语义 + `ctx.sessionPersistence`（compact 检查点
  标记 = 最后一个 `compaction/summary` 事件），不需要 SQLite FTS。
- `MAX_BLOCK_CHARS = 400`（单块内容上限）。

### 4.2 方法详解

- `resolve(reference) -> {"session_id", "header", "blocks", "truncated"}`
  - `reference = {"session_id", "before_seq"?, "max_blocks"?, "max_chars"?}`；
  - 加载：活跃会话（`ctx.sessions`）优先，否则
    `persistence.inspect(session_id)`（无持久化后端 → `SessionError`）；
  - 窗口 = 最后 compact 检查点之后 → `before_seq`（含）；
  - 投影表面：user/message → {source: data.source|{kind:user}, content}；
    assistant/message → 文本/推理块拼接 + 工具调用渲染
    `[调用工具 name]`，source={kind:model, provider, model}；
    tool/result → {kind:tool, name}；compaction/summary →
    「（此前上下文已压缩）」前缀；
  - **边界**：从尾部取最多 max_blocks 块、累计 ≤ max_chars；越界截断
    truncated=True；只读（全新对象）。
