# 持久化与执行（持久化 / 文件系统 / 子进程）开发手册

> 对应 TS 版概念：`persistence.md` 的 `SessionPersistence` 契约、JSONL 后端、`fs/*` 事件与 `fs-observation-policy`、`dsh-base` 平台条件终端行。
> 源码文件清单：`dsh/persistence/service.py`、`dsh/persistence/jsonl.py`、`dsh/persistence/sqlite.py`、`dsh/fs/fs.py`、`dsh/fs/local.py`、`dsh/fs/tool_fs.py`、`dsh/subprocess/local.py`、`dsh/subprocess/tool_bash.py`。
> 生成方式：人工完整读取上述源码，并用 `python -c "import inspect; ..."` 逐个验证签名后撰写；仅记录代码真实行为。

## 1. 模块定位与架构位置

**职责**：三个可替换的能力缝——
1. **持久化**：`SessionPersistence`（`ctx.sessionPersistence`）抽象 + JSONL 文件后端 + SQLite 后端（默认禁用，与 JSONL 互斥），订阅 `session/event` 异步缓冲、`session/flush` 排空、`load` 崩溃修复。
2. **文件系统**：`FsService`（`ctx.fs`）抽象 + `LocalFsService` 工作区受限实现 + 五个文件工具（`fs_read/fs_write/fs_edit/fs_glob/fs_grep`）。
3. **子进程**：`SubprocessService`（`ctx.subprocess`）本地执行 + `bash` 终端工具（Windows=pwsh，POSIX=bash）。

**ctx 服务名与 provides/inject**：

| 类 | provides | inject | ctx.<key> |
|---|---|---|---|
| `SessionPersistence` | `"sessionPersistence"` | — | `ctx.sessionPersistence` |
| `JsonlPersistence` | 继承 `"sessionPersistence"` | — | 同上 |
| `SqlitePersistence` | 继承 `"sessionPersistence"` | — | 同上 |
| `FsService` | `"fs"` | — | `ctx.fs` |
| `LocalFsService` | 继承 `"fs"` | — | 同上 |
| `ToolFsPlugin` | `None` | `("tools",)` | 消费 `ctx.tools` |
| `SubprocessService` | `"subprocess"` | — | `ctx.subprocess` |
| `ToolBashPlugin` | `None` | `("tools", "subprocess")` | 消费 `ctx.tools`/`ctx.subprocess` |

**与其他模块的调用关系**：
- `SessionPersistence.apply` 订阅 `session/event`（同步入缓冲）与 `session/flush`（排空）；`SessionStore._publish` 在 append 时同步广播 `session/event`。
- `JsonlPersistence`/`SqlitePersistence` 读写 `SessionHeader`/`SessionEvent`，写盘用 `asyncio.to_thread` 不阻塞事件循环（SQLite 单库两表、`check_same_thread=False`）。
- `LocalFsService` 用 `ToolError` 做工作区围栏与编辑校验；`guard_write/guard_edit` 走 `fs/write-intent`/`fs/edit-intent` waterfall + 观察策略。
- `tool_fs`/`tool_bash` 的工具体经 `ctx.tools.register` 注册；执行时经 `ctx.fs`/`ctx.subprocess`/`ctx.jobs`。
- `AgentLoopService.resume` 依赖 `ctx.sessionPersistence`；`bash` 后台模式依赖 `ctx.jobs`。

**能力缝三角色分析**：
- **持久化**：Definition=`SessionPersistence`（ABC + 缓冲/flush/load 契约），Provider=`JsonlPersistence`/`SqlitePersistence`（互斥二选一），Consumer=`AgentLoopService.resume`/`SessionStore.flush`。
- **文件系统**：Definition=`FsService`（ABC + 观察策略），Provider=`LocalFsService`，Consumer=`fs_*` 工具（换 provider 即换存储后端）。
- **子进程**：Provider=`SubprocessService`（`ctx.subprocess`），Consumer=`bash` 工具。

## 3. 类型与数据结构

**`FileDiff`（`@dataclass`）字段表**：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `path` | `str` | （必填） | 相对工作区路径 |
| `old_text` | `Optional[str]` | （必填） | 写前原文（新建为 `None`） |
| `new_text` | `str` | （必填） | 写后全文 |

**`RunResult`（`@dataclass`）字段表**：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `stdout` | `str` | （必填） | 标准输出（UTF-8，`errors="replace"`） |
| `stderr` | `str` | （必填） | 标准错误 |
| `exit_code` | `int` | （必填） | 退出码 |
| `timed_out` | `bool` | `False` | 是否超时硬杀 |
| `aborted` | `bool` | `False` | 是否因取消信号中止 |

**`SessionPersistence` 内部状态**：`_buffers: Dict[str, List[SessionEvent]]`、`_buffer_lock: threading.Lock`、`_write_lock: asyncio.Lock`、`_failed: set`（写失败会话集）、`_closed: bool`。

**`SqlitePersistence` 内部状态**：`path`（默认 `~/.dsh/sessions.db`）、`_io_lock: threading.Lock`、`_conn: Optional[sqlite3.Connection]`。

**`FsService` 内部状态**：`_observed: set`（已读路径）、`_require_read_before_write: bool`（配置 `require_read_before_write`，默认 False）。

### 4.1 `dsh/persistence/service.py`

#### `SessionPersistence`（`Service` + `ABC`，`provides="sessionPersistence"`）
```python
def __init__(self, ctx, config: Optional[dict] = None) -> None:
def apply(self, ctx) -> None:
```
- `apply`：`ctx.set("sessionPersistence", self)`；`ctx.on("session/event", self._on_event)`、`ctx.on("session/flush", self._on_flush)`。

```python
def _on_event(self, session: Session, event: SessionEvent) -> None:
```
- 加 `_buffer_lock`；若 `session.id in _failed` 直接返回（暂停自动重试，等显式 flush）；否则 `_buffers.setdefault(id, []).append(event)`。

```python
async def _on_flush(self, session: Session) -> bool:
```
- `await self.flush(session)`；返回 `True`。

```python
async def flush(self, session: Session) -> None:
```
- 加锁弹出该会话批次；空则返回；`async with _write_lock`：`_write_batch` 成功后 `_failed.discard(id)`；失败 → 记日志、`_failed.add(id)`、把批次放回缓冲、`raise`。

```python
@abstractmethod
async def _write_batch(self, session, events: List[SessionEvent]) -> None:
@abstractmethod
async def _load_raw(self, session_id: str) -> Tuple[SessionHeader, List[dict]]:
@abstractmethod
async def list_ids(self) -> List[str]:
```
- 后端契约（抽象方法）。

```python
def locate(self, session: Session) -> Optional[str]:
```
- 默认返回 `None`（JSONL 覆写返回绝对路径，SQLite 返回 None）。

```python
async def load(self, session_id: str) -> Tuple[SessionHeader, List[dict]]:
```
- `header, rows = await _load_raw(session_id)`；`repair_open_turn(rows)` 修复后返回。

```python
async def inspect(self, session_id: str) -> Tuple[SessionHeader, List[dict]]:
```
- 轻量检视：默认 `return await self.load(session_id)`（后端可覆写为不修复/只读头部的实现）；会话查询（`ctx.sessionQuery`）用此取 header 与事件。

```python
@staticmethod
def repair_open_turn(rows: List[dict]) -> List[dict]:
```
- 遍历行追踪 `depth`（`turn/start` +1、`turn/end` -1）与 `open_turn`；末尾 `depth>0` 且 `open_turn` 非空 → 追加合成 `{"type":"turn/end","seq":last_seq+1,"time":now_ms,"data":{"turn":open_turn,"reason":{"kind":"interrupted"}}}`（不截断原日志）。

```python
def known_event_types(self) -> set:
```
- `set(EVENT_CATALOG.keys())`。

```python
def close(self) -> None:
```
- `_closed=True`、清空 `_buffers`。

### 4.3 `dsh/persistence/sqlite.py`

#### `SqlitePersistence`（`SessionPersistence`）

```python
def __init__(self, ctx, config: Optional[dict] = None) -> None:
```

`self.path = os.path.expanduser((config or {}).get("path", "~/.dsh/sessions.db"))`；`_io_lock = threading.Lock()`、`_conn: Optional[sqlite3.Connection] = None`。

```python
def apply(self, ctx) -> None:
```

`super().apply(ctx)`；`os.makedirs(dirname(path), exist_ok=True)`。

```python
def _connect(self) -> sqlite3.Connection:
```

惰性建连：`sqlite3.connect(self.path, check_same_thread=False)`（跨 `to_thread` 线程共享单连接，配 `_io_lock` 串行化）；`PRAGMA user_version = 1`；`CREATE TABLE IF NOT EXISTS sessions(session_id TEXT PRIMARY KEY, header TEXT NOT NULL)` 与 `events(session_id TEXT NOT NULL, seq INTEGER NOT NULL, event TEXT NOT NULL, PRIMARY KEY(session_id, seq))`（单库两表）；`commit`。

```python
def locate(self, session: Session) -> Optional[str]:
```

返回 `None`（会话共享一个数据库）。

```python
async def _write_batch(self, session: Session, events: List[SessionEvent]) -> None:
```

`header_json = json.dumps(_header_to_json(session.header), ensure_ascii=False)`；`_write`（持 `_io_lock`）：`INSERT OR REPLACE INTO sessions` 写 header，`executemany` `INSERT OR REPLACE INTO events`（每事件一行 JSON）写事件，`commit`；`await asyncio.to_thread(_write)`。

```python
async def _load_raw(self, session_id: str) -> Tuple[SessionHeader, List[dict]]:
```

`_read`（持 `_io_lock`）：查 `sessions` 得 header 行（无则返回 `(None, [])`），再按 `seq` 升序读 `events` 每行 JSON 得事件行列表；`await asyncio.to_thread`；header 为 None → `SessionError("session ... not found in {path}")`；返回 `(header, rows)`（版本/seq/未知必填/崩溃修复由基类 `SessionPersistence.load` 统一做）。

```python
async def list_ids(self) -> List[str]:
```

`SELECT session_id FROM sessions`（`fetchall`）；`await to_thread`。

```python
def close(self) -> None:
```

`super().close()`；`_conn` 非 None 时持 `_io_lock` 关闭并置 None。

模块级 `_header_to_json(header)` / `_header_from_json(raw)`：`SessionHeader` ↔ dict 全字段往返（含 `agent_preset`；`version`/`created_at`/`delegation_depth` 转 int）。

### 4.5 `dsh/fs/local.py`

#### `LocalFsService`（`FsService`）
```python
def __init__(self, ctx, config: Optional[dict] = None) -> None:
```
- `self._root = os.path.abspath((config or {}).get("root", os.getcwd()))`。

```python
def workspace_root(self) -> str:
def resolve(self, path: str) -> str:
```
- `resolve`：绝对路径直接用，相对路径 `abspath(join(_root, path))`；`normpath` 后若不等于根且不以 `root + os.sep` 开头 → `raise ToolError("path ... escapes workspace root ...", code="OUTSIDE_WORKSPACE")`（含 `..` 逃逸）。

```python
async def read_text(self, path: str) -> str:
```
- `resolve`；不存在 → `ToolError(code="NOT_FOUND")`；是目录 → `ToolError(code="IS_DIRECTORY")`；`await to_thread(_read)`；`observe(path)`；返回内容。

```python
@staticmethod
def _read(absolute: str) -> str:
```
- `open(..., "r", encoding="utf-8", errors="replace")` 读全文。

```python
async def write_text(self, path: str, content: str) -> FileDiff:
```
- `resolve`；`await guard_write(path)`；存在则 `old_text = await read_text(path)`（否则 None）；`await to_thread(_write)`；返回 `FileDiff`。

```python
@staticmethod
def _write(absolute: str, content: str) -> None:
```
- `makedirs(parent, exist_ok=True)`；`open(..., "w", encoding="utf-8", newline="\n")` 写。

```python
async def edit_text(self, path: str, old_text: str, new_text: str) -> FileDiff:
```
- `resolve`；`await guard_edit(path)`；不存在 → `NOT_FOUND`；`to_thread(_read)` 取当前；`count = current.count(old_text)`：0 → `NO_MATCH`、>1 → `AMBIGUOUS_MATCH`（附命中次数）；`replace(..., 1)`；`to_thread(_write)`；返回 `FileDiff(path, old_text, updated)`。

```python
async def exists(self, path: str) -> bool:
```
- `resolve` 抛 `ToolError` → `False`；否则 `os.path.exists`。

### 4.6 `dsh/fs/tool_fs.py`

#### `build_tools`（模块级函数）


```python
async def run(self, command: List[str], *, cwd=None, timeout=None, signal=None,
              env=None, stdin_data=None) -> RunResult:
```
- `timeout` 缺省用 `_default_timeout`；`stdin_data` 非 None → `stdin=PIPE` 并在
  `communicate(input=stdin_data.encode("utf-8"))` 时写入（hooks 兼容桥的
  Claude stdin JSON 契约用，第十一批）；
  `create_subprocess_exec(*command, cwd=cwd, stdout=PIPE, stderr=PIPE, env=env)`
  （`shell=False`，无注入面），`OSError` → `ToolError(code="SPAWN_FAILED")`；
  生成后若 `ctx.has("sandbox")` → `ctx.sandbox.attach(process.pid)`（沙箱缝
  消费点，identity 后端 no-op）；`signal` 非空则起 `_watch` 后台 task
  （`await signal.wait()` → `process.kill()`，`ProcessLookupError` 忽略）；
  `wait_for(process.communicate(), timeout)` 超时 → `_kill()` + 再
  communicate + 返回 `RunResult("","", returncode or -1, timed_out=True)`；
  正常返回 `RunResult(stdout.decode("utf-8","replace"), stderr.decode(...),
  returncode or 0, aborted=signal.aborted)`；`finally` 取消 abort_task。

## 5. 关键流程

### 5.1 JSONL 写读与崩溃修复流程（伪代码）

```
写：
Session.append(event)  →  SessionStore._publish 同步 emit("session/event", session, event)
  →  SessionPersistence._on_event 加锁入缓冲（_failed 会话跳过）
SessionStore.flush(session)  →  emit("session/flush", session)
  →  SessionPersistence._on_flush  →  flush(session)
       batch = pop 缓冲；空则返回
       with _write_lock:
           _write_batch(session, batch)   # JsonlPersistence: to_thread 追加写
           成功 → _failed.discard(id)
           失败 → _failed.add(id) + 放回 batch + raise

读 + 崩溃修复：
load(session_id):
```

### 5.2 文件写入/编辑的安全链路（伪代码）
```
write_text(path, content):
  absolute = resolve(path)                 # 越界 → ToolError(OUTSIDE_WORKSPACE)
  await guard_write(path)                  # fs/write-intent waterfall 拒绝 → WRITE_DENIED；再 _check_write 观察策略
  old_text = read_text(path) if exists else None
  to_thread(_write)                        # 建父目录 + newline="\n" 覆盖写
  return FileDiff(path, old_text, content)

edit_text(path, old_text, new_text):
  absolute = resolve(path); await guard_edit(path)   # fs/edit-intent → EDIT_DENIED
  不存在 → NOT_FOUND
  current = to_thread(_read)
  count = current.count(old_text): 0→NO_MATCH; >1→AMBIGUOUS_MATCH
  to_thread(_write, current.replace(old_text, new_text, 1))
  return FileDiff(path, old_text, updated)
```

### 5.3 子进程执行与取消（伪代码）
```
run(command, *, cwd, timeout, signal, env, stdin_data):
  timeout = timeout or _default_timeout
  process = create_subprocess_exec(*command, cwd, stdout=PIPE, stderr=PIPE,
                                   stdin=(PIPE if stdin_data else None), env)  OSError→SPAWN_FAILED

  abort_task = (signal 非空) create_task(await signal.wait(); process.kill())
  try:
      try: stdout, stderr = await wait_for(communicate(input=(stdin_data.encode() if stdin_data else None)), timeout)
      except TimeoutError: kill(); await communicate(); return RunResult("","",returncode or -1,timed_out=True)
      return RunResult(stdout.decode(replace), stderr.decode(replace), returncode or 0, aborted=signal.aborted)
  finally: abort_task.cancel()
```

## 6. 事件与扩展点

| 事件名 | 派发方式 | 载荷 | 含义 |
|---|---|---|---|
| `session/event` | emit（订阅） | `(session, event)` | append 后同步通知，持久化插件入缓冲 |
| `session/flush` | parallel（订阅） | `(session)` | 排空该会话缓冲到 quiescence |
| `fs/write-intent` | waterfall | `{"path"}` | 写前决策；返回非 None 原因即拒绝 |
| `fs/edit-intent` | waterfall | `{"path"}` | 编辑前决策；返回非 None 原因即拒绝 |
| `fs/observed` | emit | `{"path","op":"read"}` | 读/写观察通知（观察策略、skill 订阅） |

## 7. 常见改动指引

**如何换一个持久化后端**：新建 `class XxxPersistence(SessionPersistence)`，实现 `_write_batch`/`_load_raw`/`list_ids`（可选覆写 `locate`/`inspect`）；`provides` 仍是 `"sessionPersistence"`，在 bundle 里替换 JSONL 那一行即可。`load` 的崩溃修复与 `flush` 重试语义由基类统一提供。

**如何新增一个文件系统 provider**：继承 `FsService` 实现五个抽象方法；复用 `guard_write/guard_edit/observe/_check_write` 继承的决策链。文件工具族（`tool_fs`）无需改动，换 provider 即换后端。

**如何新增一个文件工具**：在 `build_tools` 里加一个 `@define_tool(...)` 定义，通过 `_fs_of(run_ctx)` 取 provider；`ToolFsPlugin.apply` 会自动注册所有 `build_tools()` 返回的工具。

**如何调整子进程超时/目录**：`SubprocessService` 的 `config["timeout"]` 改默认超时；`run` 的 `cwd` 逐调用覆盖；`bash` 工具的 `timeout_ms=300_000` 是工具层超时，`run(timeout=300)` 是执行层超时。后台执行需要 `ctx.jobs` 服务（`ToolBashPlugin` 的 inject 未声明 `jobs`，仅运行期 `ctx.has("jobs")` 检查）。

**如何关闭 read-before-write**：`LocalFsService` 的 config `require_read_before_write` 默认 False；置 False（或不设）即关闭写前观察校验。
