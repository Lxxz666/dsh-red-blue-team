> 对应 TS 版概念：`subagent` 缝、`ctx.goals` / `goal-round-driver`、`compaction` 缝、`ctx.commands`、`ctx.jobs` / `tool-jobs`、`plan-mode`、`todo` 工具。

> 生成方式：本文由人工按代码逐类逐函数撰写；函数签名以 `python -c "import inspect; ..."` 逐一核验。

## 1. 模块定位与架构位置

本组是「高级能力」层：在脊柱（kernel/session/tools/llm/prompt/agent）之上，通过 `Service` 插件与 `ctx.<key>` 服务、`define_tool` 工具、事件监听器三类扩展点叠加能力。全部能力都由 `dsh/config/bundles/base.yml` 中的配置行挂载（见手册 09）。

服务与依赖关系（`provides` / `inject`）：

| 插件类 | provides | inject | ctx.<key> |
|---|---|---|---|
| `SubagentRegistry` | `subagents` | — | `ctx.subagents` |
| `InProcessProviderPlugin` | — | `subagents` | 注册 provider |
| `ToolSubagentPlugin` | — | `tools, subagents` | 注册 `subagent` 工具 |
| `GoalService` | `goals` | — | `ctx.goals` |
| `GoalRoundDriverPlugin` | — | `goals, agents` | 监听 `session/event` |
| `ToolGoalPlugin` | — | `tools, goals` | 注册 `goal_*` 工具 |
| `CompactionService` | `compaction` | — | `ctx.compaction` |
| `CompactionPolicyPlugin` | — | `compaction` | 监听 `agent/pre-step` |
| `CommandRegistry` | `commands` | — | `ctx.commands` |
| `BuiltinCommandsPlugin` | — | `commands` | 注册内置命令 |
| `JobsService` | `jobs` | — | `ctx.jobs` |
| `ToolJobsPlugin` | — | `tools, jobs` | 注册 `job_*` 工具 |
| `PlanModeService` | `planMode` | — | `ctx.planMode` |
| `PlanModePlugin` | — | `planMode, tools, systemPrompt` | 提示分节 + 只读守卫 + 工具 |
| `ToolTodoPlugin` | — | `tools` | 注册 `todo_write` 工具 |

与其它模块的调用关系：

- 子代理 `InProcessSubagent.run` 通过 `parent._factory.ctx.agents.create(...)` 复用 `AgentRegistry`/`AgentLoopService`（父作用域继承）；工具 `subagent` 经 `run_ctx.execution.agent` 取父 agent。
- goal 的续轮驱动监听 `session/event`，用 `ctx.agents.get(session.id)` 找到 agent，再 `agent.followup(...)` 注入下一条面向模型的用户消息。
- compaction 挂在 `agent/pre-step`（waterfall，`prepend=True` 最先执行），压缩结果以 `surface_op="replace"` 落日志。
- commands 由 server 的 `post_message` 在消息以 `/` 开头时直派发（不经过模型 turn）。
- jobs 直接以 `asyncio.create_subprocess_exec` 起子进程；工具 `job_output`/`job_kill`/`job_list` 面对模型。
- plan 在 `tools/pre-execute` 上注册只读守卫（waterfall 返回 `DenyDecision` 短路工具执行）。
- todo 直接 `agent.session.append("todo/write", ...)` 落日志（不进派生历史）。

#### 类 `InProcessSubagent`

```python
def __init__(self) -> None
```
`self.name = "in-process"`。

```python
async def run(self, parent: Any, description: str, prompt: str,
              max_tokens: Optional[int] = None) -> str
```
参数：`parent` 父 `Agent`；`description` 任务概述（本实现未使用，仅为接口契约）；`prompt` 自包含任务说明；`max_tokens` 覆盖子 agent 的 `max_tokens`。

行为细节（继承父作用域完整流程）：
1. `registry = parent._factory.ctx.agents`，`sessions = parent._factory.ctx.sessions`（同一 `AgentLoopService`，同一插件实例/工具注册，天然继承父作用域）。
2. 构造 `meta`：`cwd` 取父会话头 `cwd`，`parent_session=parent.id`，`delegation_depth=parent.session.header.delegation_depth + 1`，`origin="subagent"`（fork 血缘 + 委托深度）。
3. `options = dict(parent.options)`；若 `max_tokens` 非空则覆盖。
4. `child = await registry.create(options=options, meta=meta)`。
5. `child.followup(prompt, source={"kind": "plugin", "plugin": "subagent"})` → `await child.when_idle()` → `await asyncio.sleep(0.01)`（让 `turn/end` 与派生缓存稳定）。
6. 取 `child.session.derive_messages()` 中最后一条 `assistant` 消息，返回 `plain_text()`；无则返回 `""`。
7. `finally`：`AgentHandle(child).dispose()` 确保子 agent 生命周期被回收。

副作用：创建并销毁一个子会话/子 agent（会落盘子会话日志，除非被 dispose 清除）；异常会向上传播。

#### 函数 `build_subagent_tool`

```python
def build_subagent_tool(default_provider: str = "in-process") -> Any
```
构造并返回 `subagent` 工具（`@define_tool`）。`parameters`：`description`（string, required）、`prompt`（string, required）；`output`：`{"type": "string"}`。

工具体 `subagent_tool(args, run_ctx)`：
- `agent = run_ctx.execution.agent`；为 `None` 抛 `ToolError("subagent requires a parent agent", code="NO_AGENT")`。
- `ctx = agent.ctx if hasattr(agent, "ctx") else run_ctx.root_ctx`；`registry = ctx.subagents`。
- `provider = registry.get(default_provider)`；为 `None` 抛 `ToolError(..., code="NO_PROVIDER")`。
- `return await provider.run(agent, args["description"], args["prompt"])`（注意：不传 `max_tokens`）。
- 任何异常包装为 `ToolError(f"subagent failed: {exc}")`。


一轮结束：目标不存在或 `status != "active"` 直接返回原 goal（不递增）；否则 `completed_rounds += 1`；若 `completed_rounds >= max_rounds` 则置 `status="blocked"`、`blocker_reason="goal round limit reached"`；`emit("goal/changed", ...)`；返回 goal。

#### 类 `GoalRoundDriverPlugin`（inject=`("goals", "agents")`）


`apply`：`self._disposer = ctx.on("session/event", self._on_event)`，返回 `cleanup` 注销。

```python
def _on_event(self, session: Any, event: Any) -> None
```
- 仅处理 `event.type == "turn/end"`，否则返回。
- `agent = self.ctx.agents.get(session.id)`，无则返回。
- `goal = self.ctx.goals.finish_round(agent.ctx_name)`；若 `goal` 为 `None` 或 `status != "active"` 返回。
- 否则 `agent.followup(f"[目标续轮 {goal.completed_rounds}/{goal.max_rounds}] 继续完成目标：{goal.objective}", source={"kind": "goal", "goal_id": goal.id})` 注入续轮消息。

#### 函数 `build_goal_tools`

```python

```
返回 `[goal_create, goal_status, goal_complete]` 三个 `@define_tool` 工具。

内部辅助 `_scope_of(run_ctx)`：`agent = run_ctx.execution.agent`；返回 `agent.ctx_name if agent is not None else None`。

- `goal_create`（parameters：`objective`(string, required)、`max_rounds`(integer)；output string）：`scope` 为 `None` 抛 `ToolError(code="NO_AGENT")`；`ctx = run_ctx.root_ctx if agent is None else agent.ctx`；`goal = ctx.goals.create(scope, args["objective"], max_rounds=int(args.get("max_rounds") or 5))`；返回 `f"goal created: {goal.id}"`。
- `goal_status`（parameters：{}；output object）：`scope` 为 `None` 返回 `None`；返回 `goal.to_json()` 或 `None`。
- `goal_complete`（parameters：{}；output string）：`ctx.goals.update(scope, status="completed")`；返回 `"goal completed"`（注意：此处未判空 `scope`，但 `update` 对不存在的 scope 是安全 no-op）。

### 4.3 `dsh/compaction/compaction.py`

#### 模块级：事件注册与估算

模块导入时执行 `register_event_type("compaction/summary", "...", surface=True)` —— 把该事件注册为 surface（消息产生型）事件。`TOKENS_PER_CHAR = 4`。

```python
def estimate_tokens(messages: List[Any]) -> int
```
粗估：对每条消息求 `sum(len(block.text or "") for block in message.content) // TOKENS_PER_CHAR` 累加（注意是逐消息做整除，非总量整除），即约 4 字符 ≈ 1 token。

#### 类 `CompactionService`（provides=`compaction`）

```python
def __init__(self, ctx, config: Optional[dict] = None) -> None
```
`threshold_tokens = int((config or {}).get("threshold_tokens", 8000))`；`keep_last_messages = int((config or {}).get("keep_last_messages", 4))`。

```python
def apply(self, ctx) -> None
```
`ctx.set("compaction", self)`。

```python
async def compact(self, agent: Any) -> Dict[str, Any]
```
返回 `{"compacted": bool, "summary": str, "shadowed": [seqs]}`。行为：
1. `nodes = list(session.surface.nodes)`；`len(nodes) <= keep_last_messages` 直接返回 `{"compacted": False, "summary": "", "shadowed": []}`。
2. `shadowed = nodes[:-keep]`（最旧区间）；空则同上返回。
3. `history = session.derive_messages()`；`to_summarize = history[:len(history) - keep]`。
4. `summary = await self._summarize(agent, to_summarize)`。
5. `session.append("compaction/summary", {"summary": summary}, surface_op={"op": "replace", "start": shadowed[0], "end": shadowed[-1]}, source_event_seqs=shadowed)` —— 关键：以 surface replace 事件把被遮蔽节点替换为摘要（派生历史重建）。
6. 返回 `{"compacted": True, "summary": summary, "shadowed": shadowed}`。

```python
async def _summarize(self, agent: Any, messages: List[Any]) -> str
```
- `text = "\n".join(m.plain_text() for m in messages)`。
- 构造 `LlmRequest(config=LlmCallConfig(provider=agent.options.get("provider") or "mock", model=agent.options.get("model") or "mock"), messages=[], system="把以下对话历史压缩成不超过 500 字的要点摘要，保留任务目标、已做工作与未完成事项：\n\n" + text[:6000])`。
- 通过 `agent._factory.ctx.llm.stream(request)` 流式收集，用 `AssistantAssembler` 折叠，取 `result["blocks"]` 里所有文本拼接 `summary`。
- 成功且非空返回 `f"[早前对话摘要]\n{summary}"`；任何异常 `log.exception` 后回退返回 `"[早前对话摘要]\n" + text[-2000:]`（截取末尾 2000 字符兜底）。

#### 类 `CompactionPolicyPlugin`（inject=`("compaction",)`）

```python
def __init__(self, ctx, config: Optional[dict] = None) -> None
def apply(self, ctx) -> None
```
`apply`：`self._disposer = ctx.on("agent/pre-step", self._on_pre_step, prepend=True)`（prepend 使其在其它 pre-step 监听器之前运行）。

```python
async def _on_pre_step(self, payload: Dict[str, Any], next)
```
`agent = payload.get("agent")`；非空时 `messages = agent.session.derive_messages()`；若 `estimate_tokens(messages) > self.ctx.compaction.threshold_tokens` 则 `await self.ctx.compaction.compact(agent)`；最后 `return await next()`（洋葱中间件向下委派）。

#### 类 `BuiltinCommandsPlugin`（inject=`("commands",)`）

```python
def __init__(self, ctx, config: Optional[dict] = None) -> None
def apply(self, ctx) -> None
```
`apply` 定义 5 个内部命令并注册：

- `cmd_help(agent, args)`：遍历 `commands.list()` 拼成 `"/name - description"` 列表返回。
- `cmd_goal(agent, args)`：`objective = " ".join(args)`；空则返回 `"用法: /goal <目标描述>"`；否则 `ctx.goals.create(agent.ctx_name, objective)` + `agent.followup(f"创建目标: {objective}，开始执行。", source={"kind": "goal"})`，返回 `f"目标已创建: {objective}"`。
- `cmd_compact(agent, args)`：`not ctx.has("compaction")` 返回 `"compaction 服务未挂载"`；否则 `asyncio.get_running_loop().create_task(ctx.compaction.compact(agent))`（fire-and-forget），返回 `"已触发压缩"`。
- `cmd_new(agent, args)`：返回提示文案「在 UI 中点击「新会话」即可；headless 每次运行都是新会话。」（命令层不做清空）。
- `cmd_plan(agent, args)`：`ctx.has("planMode")` 为假返回 `"plan-mode 服务未挂载"`；否则取 `mode = ctx.planMode`；`args[0] == "off"` 时 `mode.exit(agent)` 返回 `"已退出计划模式"`；否则 `mode.enter(agent)` 返回进入提示。

注册表：`[("help", ...), ("goal", ...), ("compact", ...), ("new", ...), ("plan", ...)]`，逐个 `commands.register(name, handler, description)`。之后 `self._disposers.append(lambda: None)`（占位 no-op；注释称「注销 = 移除内置命令」，但当前实现未真正反注册命令）。`cleanup` 逐个调用 disposer。

#### 类 `JobsService`（provides=`jobs`）

```python
def __init__(self, ctx, config: Optional[dict] = None) -> None
```
`self._jobs: Dict[str, Job] = {}`。

```python
def apply(self, ctx) -> None
```
`ctx.set("jobs", self)`。

```python
def spawn(self, command: List[str], cwd: str, timeout: float = 300) -> str
```
`job = Job(new_job_id(), command, cwd, timeout)`；存入 `_jobs`；`job.task = asyncio.get_running_loop().create_task(self._run(job))`；返回 `job.id`。

```python
async def _run(self, job: Job) -> None
```
- `job.process = await asyncio.create_subprocess_exec(*job.command, cwd=job.cwd, stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.STDOUT)`（stderr 合并到 stdout）。
- `job.status = "running"`。
- 循环：`line = await asyncio.wait_for(job.process.stdout.readline(), timeout=self.timeout)`（每次 readline 独立计时）；`if not line: break`；`job.output_chunks.append(line.decode("utf-8", "replace"))`。
- `asyncio.TimeoutError`：`job.status = "timeout"`，`job.process.kill()`，`await job.process.wait()`，return。
- 正常 EOF：`job.exit_code = await job.process.wait()`；`job.status = "killed" if job.status == "killed" else ("done" if job.exit_code == 0 else "failed")`（即 `kill()` 已置 `killed` 时保持 killed，避免被覆盖成 done/failed）。
- 任何其它异常：`log.exception`，`job.status = "failed"`，追加 `[job error] {exc}\n`。

```python
def get(self, job_id: str) -> Optional[Job]
```
按 id 取任务，无则 `None`。

```python
def list(self) -> List[Job]
```
返回全部任务对象列表（插入序）。

```python
def output(self, job_id: str, offset: int = 0) -> str
```
`job = self.get(job_id)`；无则 `raise ToolError(f"unknown job: {job_id}", code="UNKNOWN_JOB")`；返回 `job.output_since(offset)`。

```python
async def kill(self, job_id: str) -> None
```
无该任务抛 `ToolError(code="UNKNOWN_JOB")`；若 `job.process` 非空且 `returncode is None` 则 `job.process.kill()`；`job.status = "killed"`。

```python
def close(self) -> None
```
遍历全部 job：kill 仍运行的进程、cancel `job.task`；`self._jobs.clear()`。

## 5. 关键流程

### 5.1 子代理继承父作用域的完整流程
`subagent` 工具被调用 → `build_subagent_tool` 工具体取 `run_ctx.execution.agent`（父 agent）→ `ctx.subagents.get("in-process")` → `InProcessSubagent.run(parent, description, prompt)`：复用 `parent._factory.ctx.agents`（同一 `AgentLoopService` 实例）`create(options=父 options 副本, meta={cwd, parent_session, delegation_depth+1, origin})` → 子 agent 在父作用域上下文上 `followup(prompt)` 跑一个完整 turn（工具注册、系统提示、审批、LLM 都继承同一实例）→ `when_idle` → 取最后 assistant 文本返回 → `AgentHandle.dispose` 销毁子 agent。这样「同接口背后换 provider」的 `subagent` 缝得以成立。

### 5.2 goal 续轮触发链路
`turn/end` 落日志 → `session/event` 被 `GoalRoundDriverPlugin._on_event` 捕获 → `ctx.agents.get(session.id)` 找 agent → `ctx.goals.finish_round(scope)`（completed_rounds+1，达上限置 blocked）→ 仍 active 则 `agent.followup("[目标续轮 n/m] 继续完成目标：...", source={"kind":"goal"})` 唤醒驱动开新 turn。`/goal` 命令或 `goal_create` 工具创建目标，`goal_complete` 工具/`update(status="completed")` 停止续轮。

### 5.3 压缩的 replace 落日志流程
`agent/pre-step`（waterfall，prepend）先运行 `CompactionPolicyPlugin._on_pre_step`：`estimate_tokens(derive_messages()) > threshold_tokens` 则 `compact(agent)`。`compact` 取 `surface.nodes` 最旧区间 `shadowed`，用模型（或 mock/回退）总结 `to_summarize`，`session.append("compaction/summary", ..., surface_op={"op":"replace","start":shadowed[0],"end":shadowed[-1]}, source_event_seqs=shadowed)`。`SurfaceManager.validate/commit` 校验 replace 区间合法、遮蔽节点完整声明，然后删除被遮蔽节点、把摘要 seq 追加到 surface、`replace_generation += 1`，派生历史缓存失效重建——模型看到「摘要替代旧历史」。

### 5.4 命令派发流程
用户在 UI 输入 `/xxx args` → server `post_message` 识别 `/` 前缀 → `ctx.commands.dispatch(agent, text)`：strip、切分命令名与参数、查表、调 handler、返回 `{"handled", "reply"}`。`/help` 列命令；`/goal` 创建目标并 `followup`；`/compact` 异步触发压缩；`/plan`/`/plan off` 切换计划模式；`/new` 返回提示。非命令输入返回 `handled=False`。

## 7. 常见改动指引

- **新增一个子代理 provider**：实现 `run(agent, description, prompt) -> 文本`（async 或 sync），然后 `ctx.subagents.register("name", provider)`（或新增一个 `Service` 插件 `inject=("subagents",)` 在其 `apply` 中注册）。切换默认 provider：`build_subagent_tool(default_provider=...)` 或在 `ToolSubagentPlugin` 注册时传参。
- **新增一条命令**：`ctx.commands.register("name", handler, description)`，`handler(agent, args) -> Optional[str]`（可在 handler 内 `agent.followup(...)` 注入后续工作）。内置命令加在 `BuiltinCommandsPlugin.apply` 的注册表元组里。
- **新增一个 goal 工具**：仿 `build_goal_tools` 内的 `@define_tool` 增加 `goal_xxx`，加入返回列表；需在 `ToolGoalPlugin` 注册。若要改续轮节奏，改 `GoalService.finish_round` 的阈值判定或 `GoalRoundDriverPlugin._on_event`。
- **调整压缩策略**：`CompactionService.__init__` 支持 `threshold_tokens`/`keep_last_messages` 两个 config；可在 `base.yml` 的 `compaction` 行 `config:` 或 patch 层覆盖。
- **新增一个只读工具名**：向 `READ_ONLY_TOOL_PREFIXES` 加前缀，使计划模式下放行。
- **关闭计划模式写守卫**：在 patch 中 `disable: [plan-plugin]`（但保留 `plan-mode` 供 `/plan` 提示）。
- **禁用某个内置工具**：在 `cordis.patch.yml` 中 `- disable: [tool-goals]`、`[tool-jobs]`、`[tool-subagent]`、`[todo-tool]` 等（对应 `base.yml` 的 id）。
